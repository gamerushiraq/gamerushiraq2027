# GameRush Iraq v1 — Frontend

This is the first deployable UI build: Arabic-first responsive PWA shell, home page, game catalog, game detail/checkout flow, rewards/services sections, animations, and mobile layout.

## Important
Prices shown in this prototype are placeholders for UI only. They are NOT approved market prices and must not be used for production checkout until supplier costs, payment fees, taxes/charges (if applicable), and Iraq SKU availability are verified.

Payment, supplier fulfillment, OAuth, OTP, social APIs, database, admin, and AI Manager are intentionally not marked as live.

## Deploy
Static hosting works on Vercel/Netlify/Cloudflare Pages. Upload the project folder or connect it to GitHub.

## Next production step
Add a real backend (PostgreSQL + server API + queue), then enable payment/supplier adapters only after credentials and live/sandbox tests pass.
